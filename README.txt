TEAMGGGIRLS — WEB PARA VS CODE Y GITHUB PAGES

1. Descomprime todo el ZIP en una carpeta.
2. Abre esa carpeta completa en VS Code (Archivo > Abrir carpeta).
3. Verifica que index.html, styles.css y script.js estén juntos en la raíz y que exista la carpeta assets.
4. Para probarlo, abre index.html con la extensión Live Server de VS Code. No abras el archivo desde dentro del ZIP.
5. Para GitHub Pages, sube el contenido de esta carpeta (index.html, styles.css, script.js y assets) al repositorio, manteniendo los nombres y rutas.

Esta versión conserva el diseño original, prioriza la sección del World Cosplay Summit (WCS) y la galería de cosplays en dúo. Se retiró la sección de premios/concursos ganados.
